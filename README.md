# Aluga Aí Gestão de Locações

Crie um protótipo navegável de um SaaS chamado "Aluga Aí".



SOBRE O PROJETO:



O Aluga Aí é um sistema de gerenciamento de locações desenvolvido para pessoas e empresas que trabalham com aluguel de diferentes tipos de produtos, equipamentos e propriedades.



Exemplos:

- Aluguel de veículos.

- Aluguel de ferramentas e equipamentos.

- Aluguel de roupas e acessórios.

- Aluguel de espaços e locais para eventos.

- Aluguel de imóveis.



O objetivo é oferecer uma plataforma simples, moderna e acessível, que qualquer pessoa consiga utilizar, mesmo sem experiência com tecnologia.



IMPORTANTE:

Este projeto é uma V1 DEMONSTRATIVA.

Precisamos de uma interface navegável, com interações visuais e dados fictícios realistas.

Não precisamos implementar pagamentos reais, integrações externas ou funcionalidades complexas neste momento.



IDENTIDADE VISUAL:



Nome: Aluga Aí.



Estilo:

- Moderno.

- Profissional.

- Minimalista.

- Intuitivo.

- Acolhedor.



Paleta:

- Roxo como cor principal.

- Branco como cor predominante.

- Cinza-claro para fundos secundários.

- Tons suaves de roxo para destaques.



Evite excesso de elementos, cores fortes em excesso e informações desnecessárias.



EXPERIÊNCIA DO USUÁRIO:



Esta é uma das prioridades mais importantes do projeto.



O sistema deve ser extremamente fácil de entender.



Considere que muitos usuários podem ser pessoas mais velhas ou pessoas com pouca familiaridade com aplicativos e computadores.



Portanto:

- Utilize botões grandes e fáceis de identificar.

- Utilize ícones acompanhados de textos.

- Evite termos técnicos.

- Utilize frases curtas e explicativas.

- Não esconda funções importantes em menus complicados.

- Utilize formulários simples.

- Mostre exemplos nos campos de preenchimento.

- Organize as informações de maneira visual.

- Evite excesso de informações em uma única tela.



O usuário nunca deve precisar adivinhar o que precisa fazer.



ESTRUTURA DO SISTEMA:



1. MENU LATERAL



Criar um menu lateral organizado com:



- Visão geral.

- Meus produtos.

- Clientes.

- Locações.

- Calendário.

- Financeiro.

- Relatórios.

- Configurações.



Cada opção deve ter um ícone e um nome.



2. DASHBOARD — VISÃO GERAL



Criar uma tela inicial profissional e intuitiva.



No topo, exibir:



"Bom dia! Seja bem-vindo ao Aluga Aí."



Adicionar uma frase:



"Gerencie suas locações de forma simples e organizada."



Criar cartões informativos com:



- Total de produtos cadastrados.

- Produtos disponíveis.

- Produtos alugados.

- Locações em andamento.

- Devoluções próximas.



Adicionar uma área chamada:



"O que você deseja fazer?"



Com quatro botões grandes:



- Cadastrar produto.

- Cadastrar cliente.

- Registrar locação.

- Consultar locações.



Adicionar também uma seção de atividades recentes.



3. MEUS PRODUTOS



Criar uma página para visualizar e cadastrar produtos disponíveis para aluguel.



Cada produto deve apresentar:



- Fotografia.

- Nome.

- Categoria.

- Valor da locação.

- Disponibilidade.

- Botão para editar.



Adicionar botão destacado:



"+ Cadastrar produto"



O formulário de cadastro deve solicitar:



- Nome do produto.

- Categoria.

- Descrição.

- Valor da locação.

- Tipo de cobrança (diária, semanal ou mensal).

- Fotografias.

- Disponibilidade.



4. CLIENTES



Criar uma página de gerenciamento de clientes.



Exibir uma lista com:



- Nome.

- Telefone.

- E-mail.

- Quantidade de locações realizadas.



Adicionar botão:



"+ Cadastrar cliente"



Formulário simples, com os campos:



- Nome completo.

- Telefone.

- E-mail (opcional).

- Observações (opcional).



5. LOCAÇÕES



Criar uma página para visualizar as locações.



Cada registro deve mostrar:



- Nome do cliente.

- Produto alugado.

- Data de retirada.

- Data prevista para devolução.

- Valor total.

- Situação da locação.



Criar indicadores visuais para:



- Em andamento.

- Aguardando retirada.

- Finalizadas.

- Atrasadas.



Adicionar botão:



"+ Registrar locação"



O formulário deve permitir selecionar um cliente, selecionar um produto, definir as datas e informar o valor.



6. CALENDÁRIO



Criar um calendário visual para acompanhar as locações e datas de devolução.



Utilizar cores e legendas para facilitar a identificação dos compromissos.



7. FINANCEIRO



Criar uma tela demonstrativa com:



- Total recebido.

- Valores pendentes.

- Receitas do mês.

- Histórico de movimentações.



Utilizar gráficos simples e fáceis de compreender.



8. RELATÓRIOS



Criar uma página com informações resumidas sobre:



- Produtos mais alugados.

- Quantidade de locações.

- Receita mensal.

- Clientes recorrentes.



FUNCIONALIDADE DO PROTÓTIPO:



Todas as páginas devem ser navegáveis.



Os botões principais devem funcionar visualmente.



Os formulários devem permitir preenchimento e apresentar feedback de sucesso.



Utilize dados fictícios para demonstrar como o sistema funcionaria.



Não utilize botões sem função ou links quebrados.



RESPONSIVIDADE:



O sistema deve funcionar tanto em computadores quanto em celulares.



No computador, utilizar menu lateral.



No celular, adaptar a navegação para uma experiência confortável.



ARQUITETURA E ORGANIZAÇÃO:



Organize a interface pensando em uma plataforma que futuramente poderá atender diferentes segmentos de locação.



Não limite o sistema a uma única modalidade de aluguel.



Mantenha uma estrutura visual consistente entre todas as páginas.



PRIORIDADE FINAL:



O resultado precisa parecer um SaaS profissional de verdade.



Não queremos apenas uma página de apresentação.



Queremos um protótipo de sistema administrativo, com dashboard, navegação entre telas, dados demonstrativos e identidade visual própria.

Você acha viável essa ideia? Responda apenas e depois criaremos



Priorize simplicidade, clareza, organização e facilidade de utilização.
